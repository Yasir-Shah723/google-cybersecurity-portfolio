## Executive Summary
This repository houses the complete set of portfolio projects completed across the Google Cybersecurity Professional Certificate. The deliverables demonstrate hands-on competencies in organizational security auditing, incident response lifecycle execution, database log analysis using SQL, risk assessments, incident handler journaling, access control automation in Python, and community security engagement.

## Technical Competencies
- **Incident Response & Defense:** NIST CSF framework (Identify, Protect, Detect, Respond, Recover), triage procedures, firewall rules, and IDS/IPS concepts.
- **Auditing & Governance:** PCI DSS, GDPR, SOC 2 gap analysis, and NIST SP 800-30 Rev. 1 risk calculations.
- **Data Querying & Log Analysis:** MariaDB/MySQL querying with conditional filters (`WHERE`, `AND`, `OR`, `NOT`, `LIKE`, `%`).
- **Security Automation:** Python 3 file stream management, list parsing, error prevention, and string manipulation.
- **Threat Intelligence & Protocol Analysis:** Packet analysis via Wireshark and tcpdump, and IoC lookup using VirusTotal.
